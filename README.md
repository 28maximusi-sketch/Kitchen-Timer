#Репозиторий Kitchen Timer (Кухонный таймер)
Описание
Kitchen Timer – это набор консольных утилит на 8 языках программирования для установки и отсчёта времени. Программа идеально подходит для кулинарии, тренировок или любых других задач, требующих точного обратного отсчёта.

Возможности
Установка времени в секундах или в формате MM:SS (например, 5:30).

Интерактивный режим – если время не задано, программа запросит его.

Отображение оставшегося времени с обновлением каждую секунду (в реальном времени).

Пауза и возобновление – нажмите p для паузы, r для возобновления, q для выхода.

Звуковой сигнал по окончании таймера (используется системный звуковой сигнал или \a).

Сохранение предустановок (в некоторых реализациях) – часто используемые времена сохраняются в файл для быстрого выбора.

Поддержка нескольких таймеров (в продвинутых версиях) – можно запускать несколько таймеров одновременно.

Кроссплатформенность – работает в Windows, macOS, Linux.

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Язык	Зависимости	Команда запуска
Python	только стандартная библиотека	python timer.py [время]
JavaScript	Node.js 14+ (без внешних модулей)	node timer.js [время]
TypeScript	Node.js + ts-node	ts-node timer.ts [время]
Go	только стандартная библиотека	go run timer.go [время]
Java	JDK 11+ (без внешних библиотек)	javac Timer.java && java Timer [время]
C#	.NET SDK 6.0+ (или компилятор csc)	csc Timer.cs && Timer.exe [время]
PHP	PHP 8.0+ (только стандартные функции)	php timer.php [время]
Ruby	Ruby 2.7+ (без внешних гемов)	ruby timer.rb [время]
Использование
text
timer [время]
время – может быть целым числом (секунды) или строкой вида MM:SS (например, 5:30).

Если время не указано, программа переходит в интерактивный режим и запрашивает его.

Управление во время отсчёта
p – поставить на паузу.

r – возобновить отсчёт.

q – выйти из программы.

+ – увеличить время на 1 минуту (в некоторых версиях).

- – уменьшить время на 1 минуту.

Примеры
bash
# Таймер на 90 секунд
python timer.py 90

# Таймер на 5 минут 30 секунд
python timer.py 5:30

# Интерактивный режим
python timer.py
Особенности реализаций
Python – использует threading для обновления времени, curses для динамического вывода (опционально), сохранение предустановок в JSON.

JavaScript – использует readline и setInterval, поддерживает паузу и возобновление.

TypeScript – строгая типизация, аналогично JavaScript.

Go – использует горутины и time.Ticker, каналы для управления.

Java – использует ScheduledExecutorService и java.util.Scanner.

C# – использует System.Timers.Timer и Console.ReadKey.

PHP – использует pcntl (для сигналов) или просто цикл с sleep.

Ruby – использует Thread и IO.select для неблокирующего ввода.

Все версии поддерживают паузу, возобновление и звуковой сигнал.
